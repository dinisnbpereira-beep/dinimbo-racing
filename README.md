# Dinimbo Racing 🏎️🦎

Race a yellow axolotl around an F1 circuit — hairpin, chicane, and big sweepers.

## Play
Open `index.html` in any browser — no build step, no dependencies.

## Controls
- **W** — accelerate
- **S** — brake / reverse
- **A / D** — steer (arrow keys also work)
- **R** — reset to the start line

## Track
Hairpin at the top, a fast chicane mid-left, and two long sweepers. Grass slows you down, so stay on the asphalt. Best lap is saved locally.
